# BLD Trainer

ルービックキューブ目隠し（3BLD / 4BLD / 5BLD / MBLD）向けの、**3-style 手順**と**レターペア**の管理・練習アプリです。
スマートフォンとパソコンのブラウザで動き、ホーム画面に追加すればオフラインでも使えます（PWA）。

## できること

### 手順の管理
- コーナー・エッジ・ウイング・Xセンター・+センターの全ケースを一覧／表（スプレッドシートと同じ行列）で表示
- 交換子 `[A, B]`、共役 `[A: B]`、括弧 `(A)2`、ワイド・スライス（`Rw` `r` `3Rw` `2R` `2-3Rw` `M` `E` `S`）、持ち替え `x y z` に対応
- **手順が正しい 3-cycle かを自動チェック**（NxN のシミュレーターで実際に回して確認。持ち替えが残る手順も可）
  - 違うケースの手順なら「実際は ○○ のケース」と表示
- 展開した手順・手数の表示、逆ケースの手順を交換子の形のまま反転して追加
- **おすすめ手順の自動生成**: アプリ内で交換子 `[セットアップ: [A, B]]` を総当たりで探し、手数と回しやすさ順に候補を表示。選ぶだけで登録でき、未登録のケースにまとめて登録することも可能（手入力も可）
  - 対応: コーナー・エッジ・ウイング・Xセンター・+センター（どのバッファでも可）。短い交換子で作れないごく一部のコーナーのケースは手入力
- **Elliott の手順表（Full Floating & More）を内蔵**: エッジ 10 バッファ・コーナー 6 バッファ、計 2768 手順（すべてシミュレーターで正しい 3-cycle であることを確認済み）。おすすめの先頭に表示し、一括登録でも優先
- 手順タブでバッファを切り替えられる（フローティングバッファの手順表もそれぞれ管理）
- 1 ケースに複数の候補手順、ステータス（未着手／練習中／覚えた／自動化）、メモ
- バッファごとに手順表を分けて保存（フローティングバッファにも使える）

### パリティ・フリップ・LTCT
- パリティ（コーナーの最後のターゲット＋エッジ 2 つの入れ替え）、フリップ（エッジ 2 つの反転）、LTCT（パリティ＋コーナー 1 つのひねり）の手順を管理
- 手順が正しいかを自動チェック（パリティで入れ替わるエッジも自動表示、間違っていれば「この手順で解けるのは…」を表示）
- パリティ・フリップは Elliott の表（各 66 手順、全て検証済み）から登録可能
- 練習（スマートキューブ含む）にも対応

### 文字の割り振り
- パーツごとに 24 か所すべての文字を自由に設定（ひらがな・アルファベット・複数文字も可）
- **展開図のステッカーを押してその場で書き換え**（Enter で次のステッカーへ）、まとめて入力、一覧で入力
- **1 文字目用・2 文字目用の 2 セットの文字**を設定可能（例: 1 文字目は子音、2 文字目は母音 → K + A = KA）。全パーツ・全 24 ステッカーそれぞれに 2 つの文字を持たせ、2 つの展開図で編集
- ペアのかな読み（KA → か、KYA → きゃ など）
- ペアがローマ字として読めるとき、かな読みを併記（例: `K` + `A` → か）

### レターペア
- 割り振りから作られる全ペアにイメージ・メモ・ステータスを登録
- 手順・レターペアとも、一覧と**表（行＝1 文字目、列＝2 文字目）**で表示。表は**想起時間（速い／普通／遅い／未練習）**かステータスで色分け

### 練習
- ペアを見て手順（またはイメージ）を思い出すフラッシュカード
- 想起時間を自動計測、4 段階の自己評価で間隔反復（SM-2 ベース）
- 出題範囲: 復習期限 / 苦手（遅い・ミス）/ 未練習 / すべて、ステータス・1 文字目で絞り込み
- 結果を遅い順に表示、苦手なものだけ再練習
- 練習中は次に出る問題も小さく表示
- キーボード操作: スペースで答え表示、1〜4 で評価

### スマートキューブ練習（コーナー・エッジ）
- GAN 製スマートキューブ（GAN356 i Carry / i Carry S / i Carry 2、GAN12 ui、GAN356 i3 など）に Bluetooth で接続
- ペアを見て実際に回すと、正しい 3-cycle になった時点で自動で正解（キューブは揃っていなくても可）
- 最初の 1 手までを想起時間、そこから正解までを実行時間として記録し、評価も自動
- 登録した手順と比べて何手目からずれたかを表示（M・ワイドムーブ・持ち替えを含む手順にも対応）
- 持ち方（上の色・前の色）を設定可能
- 使えるブラウザ: パソコン・Android の Chrome / Edge、iPhone は「Bluefy」アプリ（Safari は非対応）
- 新しめの GAN キューブで MAC アドレスを聞かれた場合は、GAN 公式アプリで確認して入力（一度だけ）

### 取り込み・書き出し
- Excel（.xlsx）・CSV・スプレッドシートからのコピー＆ペーストで取り込み
  - 表形式（1 行目＝2 文字目、1 列目＝1 文字目）とリスト形式（`ペア | 手順 | メモ`、`1文字目 | 2文字目 | 手順`）を自動判別
  - セル内の改行で区切った手順は候補として取り込み
- Excel / CSV への書き出し、JSON でのバックアップ・復元（スマホ⇔PC の移行にも）

## 出典

- エッジ・コーナーの手順表は Elliott's "Full Floating & More" スプレッドシートによるものです（元の表に「制限なく使ってよい（コピー・改変・公開・配布可）」と明記）。`scripts/extract_elliott.py` で `src/data/elliott.json` に変換しています。表は「上の行＝1 文字目、左の列＝2 文字目」の並びです。括弧を省いた記法（`A: B, C` = `[A: [B, C]]`、`a/b` = `a b a2 b' a`）にも対応しています。

## 端末間の同期（Firebase）

Firebase（メールアドレスでのログイン＋Firestore）で、複数端末のデータを自動同期できます。設定手順は [docs/firebase-setup.md](docs/firebase-setup.md) を参照してください。

## データの保存について

データは使っているブラウザの中（IndexedDB）に保存されます。サーバーには送られません。
端末間で移すときや念のための保存には、「設定 → バックアップを保存」を使ってください。
iPhone の Safari では、ホーム画面に追加して使うとデータが消えにくくなります。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # テスト
npm run build    # 本番ビルド（dist/）
```

push すると GitHub Actions でビルドされ、GitHub Pages（https://naoyuki51bld-cell.github.io/BLINDissue/）に公開されます。リポジトリの Settings → Pages で Source を「GitHub Actions」にしてください。
