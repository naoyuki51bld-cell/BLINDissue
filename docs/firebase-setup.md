# Firebase で複数端末を同期する設定手順

BLD Trainer のデータ（手順・レターペア・文字の割り振り・練習記録）を、スマホとパソコンなど複数の端末で自動同期するための設定です。
Firebase（Google のサービス）の **無料プラン（Spark）** の範囲で使えます。作業はパソコンのブラウザがおすすめです（所要 15〜20 分）。

全体の流れ:

1. Firebase のプロジェクトを作る
2. ログイン方法（メールアドレス＋パスワード）を有効にする
3. データの保存場所（Firestore）を作り、ルールを設定する
4. Web アプリを登録して「設定（firebaseConfig）」をコピーする
5. 設定をアプリに組み込む（GitHub に登録する方法か、アプリに貼り付ける方法）
6. アプリでアカウントを作ってログインする

---

## 1. Firebase のプロジェクトを作る

1. https://console.firebase.google.com を開き、Google アカウントでログインします。
2. 「**プロジェクトを作成**」（または「Firebase プロジェクトを始める」）を押します。
3. プロジェクト名に `bld-trainer` など好きな名前を入れて「続行」。
4. 「Google アナリティクス」は使わないので **オフ** にして「プロジェクトを作成」。
5. 「新しいプロジェクトの準備ができました」と出たら「続行」。

## 2. ログイン方法を有効にする（メール/パスワード）

1. 左のメニューの「**構築**」（Build）→「**Authentication**」を開き、「始める」を押します。
2. 「**Sign-in method**」（ログイン方法）タブで「**メール / パスワード**」を選びます。
3. いちばん上の「メール / パスワード」を **有効にする** にして「保存」。
   （下の「メールリンク（パスワードなしでログイン）」はオフのままで大丈夫です）
4. 同じ Authentication の「**設定**」タブ →「**承認済みドメイン**」→「ドメインの追加」で
   `naoyuki51bld-cell.github.io` を追加します。

> Google ログインではなくメールアドレスを使うのは、iPhone のホーム画面アプリや Bluefy でも確実にログインできるようにするためです。

## 3. Firestore（データの保存場所）を作る

1. 左のメニューの「構築」→「**Firestore Database**」を開き、「**データベースを作成**」。
2. ロケーションは「**asia-northeast1（東京）**」を選びます（あとから変えられません）。
3. 「**本番環境モードで開始**」を選んで「作成」。
4. 作成されたら「**ルール**」タブを開き、中身を全部消して、次をそのまま貼り付けて「**公開**」を押します。

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // ログインした本人だけが、自分のデータを読み書きできる
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

## 4. Web アプリを登録して設定をコピーする

1. 左上の「プロジェクトの概要」の横にある **歯車** →「**プロジェクトの設定**」を開きます。
2. 「全般」タブを下にスクロールし、「マイアプリ」の「**</>**」（ウェブ）ボタンを押します。
3. アプリのニックネームに `bld-trainer-web` などを入れて「アプリを登録」。
   「Firebase Hosting も設定する」には **チェックを入れません**。
4. 「Firebase SDK の追加」に表示されるコードのうち、次のような部分を丸ごとコピーします。

```js
const firebaseConfig = {
  apiKey: "AIza……",
  authDomain: "bld-trainer-xxxxx.firebaseapp.com",
  projectId: "bld-trainer-xxxxx",
  storageBucket: "bld-trainer-xxxxx.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef……"
};
```

あとで見たいときは、同じ「プロジェクトの設定」→「マイアプリ」の「SDK の設定と構成」→「構成」で表示できます。

> この設定（apiKey など）は秘密の情報ではなく、公開されても問題ありません。データは手順 3 のルールで「本人だけ」に守られています。

## 5. 設定をアプリに組み込む

次の **どちらか** を選びます。

### 方法 A（おすすめ）: GitHub に登録して、すべての端末で自動的に使えるようにする

1. https://github.com/naoyuki51bld-cell/BLINDissue/settings/variables/actions を開きます
   （リポジトリの「Settings」→ 左メニュー「Secrets and variables」→「Actions」→「**Variables**」タブ）。
2. 「**New repository variable**」を押します。
3. Name に `FIREBASE_CONFIG`、Value に手順 4 でコピーしたもの（`{` から `}` までを含む部分）を貼り付けて「Add variable」。
4. https://github.com/naoyuki51bld-cell/BLINDissue/actions を開き、左の「Deploy to GitHub Pages」→「Run workflow」→ 緑の「Run workflow」を押します。
5. 1〜2 分後に緑のチェックが付けば完了です。アプリを開き直すと（必要なら再読み込み）、「設定」タブの「端末間の同期」にログイン欄が出ます。

### 方法 B: アプリに直接貼り付ける（端末ごとに 1 回）

1. アプリの「設定」タブ →「**端末間の同期（Firebase）**」を開きます。
2. 「Firebase の設定（firebaseConfig）を貼り付け」に、手順 4 でコピーしたものを貼り付けて「保存して再読み込み」。
3. 同期したいすべての端末（iPhone の Safari、Bluefy、パソコンなど）で同じことをします。

## 6. アカウントを作ってログインする

1. **1 台目**（データが入っている端末）で、アプリの「設定」→「端末間の同期」を開きます。
2. メールアドレスとパスワード（6 文字以上）を入れて「**はじめて使う（アカウント作成）**」を押します。
   → この端末のデータがサーバーに送られます。「〇〇 で同期中（最終同期 …）」と出れば成功です。
3. **2 台目以降**は、同じメールアドレスとパスワードで「**ログイン**」を押します。
   → サーバーのデータと、その端末のデータが統合されます。

以降は、どの端末で変更しても数秒で自動的にほかの端末に反映されます。

## 同期のしくみと注意

- 手順・レターペア・練習記録は **1 件ずつ、あとから変更した方が残ります**。同じケースを 2 台で同時に編集した場合は、最後に保存した方になります。
- 削除やリセットも「消した」という記録として同期されます。
- 「バックアップから復元」や「すべて消去」をした場合、その端末の内容でサーバーを上書きします。ただし、**ほかの端末に残っているデータは、その端末が次に同期したときに戻ってくることがあります**。全部をやり直したいときは、ほかの端末でログアウトしてから行ってください。
- iPhone の Safari と、Safari から「ホーム画面に追加」したアプリ、Bluefy は、それぞれ別の端末として扱われます。それぞれでログインしてください。
- 無料プランの上限（1 日あたり読み取り 5 万回・書き込み 2 万回など）に、ふつうの使い方で届くことはありません。

## うまくいかないとき

| 表示・症状 | 対処 |
|---|---|
| 「メール/パスワードのログインが有効になっていません」 | 手順 2 の「メール / パスワード」を有効にして保存したか確認 |
| 「Firestore のルールで書き込みが拒否されました」 | 手順 3 のルールを貼り付けて「公開」したか確認 |
| 「このメールアドレスはすでに登録されています」 | 2 台目以降は「ログイン」を使う |
| ログイン欄が出てこない（方法 A） | GitHub の Variable 名が `FIREBASE_CONFIG` か、Run workflow 後にアプリを再読み込みしたか確認 |
| 「設定を読み取れませんでした」（方法 B） | `{` から `}` までを含めて貼り付けたか確認 |
| パスワードを忘れた | ログイン欄の「パスワードを忘れた」から再設定メールを送る |
